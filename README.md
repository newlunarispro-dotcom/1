## 🚀 Как играть?

Проект работает прямо из браузера без установки и регистрации.

1. Открой хаб: **[newlunarispro-dotcom.github.io/1/hub](https://newlunarispro-dotcom.github.io/1/hub)**
2. Введи свой никнейм.
3. Создай комнату и отправь 6-значный код друзьям.
4. Начинайте игру!

---

## 🕹️ Доступные игры

* 📱 **Bitva Phone** — соревнование на мощность телефона (тесты CPU, GPU, реакции).
* 🚀 **Space Arena** — космический шутер с видом сверху на выживание.
* 🌊 **Neon Fluid** — WebGL-симуляция жидкости (не игра, но красиво).
