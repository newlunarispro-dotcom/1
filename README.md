## 🌟 О проекте

**SND** — это современная веб-платформа, которая объединяет голосовую связь (WebRTC) и сетевые игры (WebSockets/Firebase). Идеальное решение для тех, кто хочет быстро собраться с друзьями, не выходя из браузера.

> 🎯 **Наша миссия:** Сделать общение и игры максимально простыми и доступными на любом устройстве.

---

## ✨ Основные возможности

- 🎤 **Голосовые комнаты:** Мгновенная передача звука в реальном времени (Peer-to-Peer).
- 🎮 **Онлайн-игры:** Встроенные мини-игры и тесты для телефонов и ПК.
- 🏠 **Система лобби:** Создавай комнаты и приглашай друзей по 6-значному коду.
- ⚡ **Сверхбыстрая работа:** Оптимизированный рендер и минимальная задержка благодаря современным веб-стандартам.
- 🔒 **Безопасность:** Прямое соединение между игроками (данные не хранятся на серверах).
- 📱 **Кроссплатформенность:** Работает на ПК, ноутбуках, планшетах и смартфонах.
